## What this means

**Width is not the mechanism, and the V13 write-up needs correcting a second time.** The margin survives at one lead, so Apnea's loss is about Apnea rather than about channel count.

`VALIDATION_V14.md` §5 named this as the outcome it would least like: a mechanism was published in `RESULTS_V13.md` and in the README on the strength of a correlation across four confounded datasets, with a counterexample — single-channel Sleep-EDF, which we win — already sitting in the results directory. This document exists so that outcome is recorded rather than quietly dropped.

The dataset screen offers a competing explanation with no channels in it: Apnea's regime gap is −0.010, so a global summary of that one-minute ECG loses nothing a finer representation recovers (`RESULTS_SCREEN.md`). Roadmap item 8 is the README correction.
